One line, under 200 characters, in which a home Wi-Fi router excuses itself for dying at the climax of a movie — entered on [make.fun](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e) for the "The Router Confesses" bounty.

The router doesn't apologise for a technical failure. It confesses to the crime: cast as the murderer in the movie's own whodunit, it cut the Wi-Fi on purpose so nobody finds out who did it. No buffering, bandwidth, or firmware jokes — the judge has heard those a thousand times.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (81 characters, stdlib only).
